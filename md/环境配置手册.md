# 环境配置手册 · NIR-Pyruspyrifolia

本项目采用**内置便携 Python 运行时**（`runtime/` 目录），Python 解释器与全部依赖都打包在项目内，**不依赖系统 Python、不依赖网络**，整个项目目录可直接拷贝到任意 Windows 机器（含无网络的工控机）离线运行。

## 1. 运行环境

| 项目 | 说明 |
| --- | --- |
| 操作系统 | Windows（64 位） |
| Python | 内置便携运行时 `runtime\python.exe`（3.14.6 embeddable） |
| 依赖 | 已全部装入 `runtime\Lib\site-packages` |
| 网络 | 运行阶段**无需联网** |

内置运行时（含 CUDA 版 torch）体积较大，约 3 GB 以上（PySide6 / pyarrow / pandas / numpy / torch 及 Python 标准库）。

## 2. 启动方式

双击项目根目录下的 `NIR-Pyruspyrifolia.bat` 即可启动图形界面。

> 启动脚本所有路径都基于脚本自身所在目录（`%~dp0`）动态计算，迁移到任何目录均无需修改。

## 3. 命令行入口（可选）

```powershell
cd d:\model\model\NIR-Pyruspyrifolia
.\runtime\python.exe -m tools.cli data\sample.parquet
```

## 4. 依赖清单（已打包进 runtime）

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| `pyarrow` | 25.0.1 | `.parquet` 读写引擎 |
| `pandas` | 3.0.6 | 表格数据处理 |
| `numpy` | 2.5.3 | 数值计算 |
| `PySide6` | 6.11.2 | 图形界面 |
| `torch` | 2.14.0+cu130 | 自编码器（无监督建模，GPU 加速） |

> GPU 加速：当前已安装 CUDA 版（cu130），RTX 3090 可自动使用 GPU 训练。
> 如需换回 CPU 版或换其它 CUDA 版本：
>
> ```powershell
> runtime\python.exe -m pip install --force-reinstall torch --index-url https://download.pytorch.org/whl/cu130
> # CPU 版：
> runtime\python.exe -m pip install --force-reinstall torch --index-url https://download.pytorch.org/whl/cpu
> ```

依赖清单文件：`requirements.txt`。

## 5. 离线迁移说明

1. 将**整个项目目录**（必须包含 `runtime/`）拷贝到目标机器，如 U 盘、移动硬盘。
2. 目标机器**无需安装 Python**、**无需联网**。
3. 双击 `NIR-Pyruspyrifolia.bat` 即可运行。

> ⚠️ 迁移时必须保持目录结构完整：`runtime/`、`QT/`、`tools/`、`config/`、`lg.png` 等都不能缺失。

## 6. 重建运行时（开发者参考）

若需在新环境重新构建 `runtime/`：

```powershell
# 1. 下载 Python 3.14.6 embeddable 并解压到 runtime/
#    https://www.python.org/ftp/python/3.14.6/python-3.14.6-embed-amd64.zip
# 2. 编辑 runtime\python314._pth，内容为：
#    python314.zip
#    .
#    Lib\site-packages
#    ..
#    import site
# 3. 引导 pip：runtime\python.exe get-pip.py
#    https://bootstrap.pypa.io/get-pip.py
# 4. 安装依赖（有 NVIDIA GPU 用 cu130 版，无 GPU 用 cpu 版）：
runtime\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cu130
# 无 GPU 时改用：runtime\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
runtime\python.exe -m pip install -r requirements.txt -i https://pypi.org/simple/
```

## 7. FAQ

**Q：双击 bat 报「Bundled runtime not found」？**
说明项目目录不完整，`runtime/` 目录缺失。请完整拷贝整个项目目录（不要只拷贝 bat 文件）。

**Q：迁移到工控机后无法运行？**
确认目标机器是 64 位 Windows；确认 `runtime/` 目录已完整拷贝且未被杀毒软件隔离。

**Q：需要联网吗？**
运行阶段完全不需要联网。
