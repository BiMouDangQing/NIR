# 数据分布核查（域偏移检测）

预训练用大量无标签光谱（`Spectrum_Data_*.parquet`，约 4.5 万样本），微调用少量
带真实标签光谱（`秋月梨光谱数据_RealValue.parquet`，1596 样本）。若两批数据分布
不一致（域偏移 / domain shift），预训练学到的特征对下游标签任务帮助有限。

本文说明**如何核查**两批样本的分布一致性，并给出当前数据的核查结果。

## 一、核查方法

用脚本 `tools/check_domain_shift.py`（纯 numpy/pandas，无 sklearn 依赖），对两批
光谱做 6 项检查：

| # | 检查项 | 判读标准 |
| --- | --- | --- |
| 1 | 逐波长均值/标准差对比 | 平均光谱相关系数越接近 1、均值绝对差越小越一致 |
| 2 | PCA 联合投影 | 两组质心距离归一化到组内散度，<1 高度重叠，>3 明显分离 |
| 3 | 马氏距离 | 标签样本超出预训练分布 95% 边界的比例，同分布应 ≈5% |
| 4 | KNN 最近邻覆盖度 | 标签→预训练最近邻距离 / 预训练内部自最近邻，≈1 覆盖良好 |
| 5 | 领域判别器 | 逻辑回归区分来源的 AUC，≈0.5 不可区分，>0.8 明显差异 |
| 6 | 标签分布对比 | 预训练 PredictedValue（仪器预测）vs 标签 RealValue（真值） |

### 用法

**方式一：GUI 界面（推荐）**

打开「分布核查」页签，选择预训练数据文件、标签数据文件、光谱字段（可选勾选
预处理 S-G 平滑 / MSC / SNV），点击「开始核查」，查看 6 项指标与三张图：
平均光谱对比、PCA 重叠、标签分布。

**方式二：命令行**

```bash
.\runtime\python.exe tools\check_domain_shift.py                          # 原始对比
.\runtime\python.exe tools\check_domain_shift.py --preprocess smooth,msc  # 预处理后对比
.\runtime\python.exe tools\check_domain_shift.py --out-json report.json   # 保存报告
```

参数：

| 参数 | 含义 | 默认 |
| --- | --- | --- |
| `--pretrain` | 预训练 parquet | `data/Spectrum_Data_20260928_144425.parquet` |
| `--label` | 标签 parquet | `data/秋月梨光谱数据_RealValue.parquet` |
| `--spectrum-column` | 光谱列名 | `SpectrumData` |
| `--n-comp` | 马氏距离/判别器的 PC 维度 | 20 |
| `--preprocess` | 对比前预处理（smooth,msc,snv） | 无 |

## 二、当前数据核查结果（2026-09-28）

数据：预训练 45644 样本 vs 标签 1596 样本，均为 1024 维。

| 检查项 | 原始 | smooth+MSC 后 |
| --- | --- | --- |
| 平均光谱相关系数 | 0.985 | 0.983 |
| 全局均值：预训练 / 标签 | 5441 / 3994（差 1447，约 36%） | 5441 / 3993（差不变） |
| PCA 质心归一化距离 | 2.93 | 2.73 |
| 马氏距离超 95% 边界比例 | **100%** | **100%** |
| KNN 覆盖度比值 | **433×** | **738×** |
| 领域判别器 AUC | **1.000** | **1.000** |
| 糖度：仪器预测 / 真值 | 13.97 [10.3, 19.8] / 11.49 [7.5, 15.8] | 同左 |

## 三、结论

**两批样本存在严重的系统性分布偏移，MSC 无法消除。**

1. **系统性强度偏移**：预训练光谱全局均值比标签光谱高约 **36%**（5441 vs 3994），
   且 MSC 校正后差异不变——说明这是**批次间的基线/增益差异**，不是样本内散射，
   MSC 只校正样本内散射、不校正批次间整体偏移。
2. **分布几乎不重叠**：领域判别器 AUC=1.0（可 100% 区分两批来源）、KNN 最近邻
   距离比值 433~738 倍、马氏距离 100% 超界，三者一致指向「标签样本在预训练
   分布之外」。
3. **糖度中心不同**：预训练数据的仪器预测糖度（均值 13.97）与标签真值（均值
   11.49）中心相差约 2.5 个单位，进一步佐证两批数据可能来自不同批次/测量条件。

### 对模型的影响

这解释了为何「样本量翻倍的新预训练模型（45415 样本）微调效果反而下降」（CV R²
0.790 → 0.747）：

- 预训练数据覆盖不到标签样本所在的光谱区域，学到的特征对标签任务帮助有限；
- 微调时标签数据用预训练的 mean/std 做 z-score 标准化，会落在分布边缘（实测约
  **-4σ**，比全局估算的 -1.1σ 更严重），编码器输入分布与预训练时不一致。

### 第三批次（0912）与跨批次预测失效

后续新增的 `0912` 数据（340 样本）是**第三批**，光谱分布与前两批都不同：

| 数据 | 光谱全局均值 | 逐波长 std 均值 | 相对预训练 |
| --- | --- | --- | --- |
| 预训练 | 5456 | 1358 | 基准 |
| 旧标签（1596） | 3994 | 1390 | 强度 73%，形状一致 |
| **0912（340）** | **2805** | **749** | 强度 51%，形状不同 |

关键在 **std（光谱形状）**：旧标签的 std 与预训练几乎相同（1390 vs 1358），差异
只是整体强度缩放，所以「标签自身 z-score」能抵消；而 0912 的 std 缩到一半
（749），说明光谱形状本身不同（更平缓），z-score 无法抵消。

**实测跨批次预测失效**：旧数据微调的模型 `165128`（旧数据上 CV R²=0.845）在 0912
上预测 R²=**-3.08**、RMSE=3.39、相关系数 0.34——完全失效。结论：**模型不能跨批次
使用**，旧模型只用于旧批次，0912 模型只用于 0912 批次。

## 四、建议（已实施 ✅）

**已落地**：微调与预测改为「数据自身 mean/std 做 z-score」（不再复用预训练 mean/std）。
同配置（新预训练模型 + 解冻 100 轮）下，CV R² 从 0.747 提升到 **0.820**、RMSE 从
0.576 降到 0.484，一举超过历史最佳，验证了该方向有效。详见《模型训练日志》。

| 方向 | 做法 | 状态 |
| --- | --- | --- |
| 核查数据来源 | 确认两批数据是否同一仪器/批次/测量条件（温度、光程、增益），36% 强度差通常意味着条件不同 | 待查 |
| 批次校正 | 合并建模前做**批次校正**（如按批次 MSC 后再全局 z-score，或对标签批单独重新标准化） | 采用「按批次各自 z-score」 |
| 筛选同源预训练数据 | 从 `Spectrum_Data` 中筛选与标签样本同批次/同条件、或 PredictedValue 与 RealValue 范围重叠的样本做预训练 | 待查 |
| 对齐标准化 | 微调时用**标签数据自身的** mean/std 标准化，而非复用预训练的 | ✅ 已实施 |
| 跨批次使用 | 不同测量批次（旧标签 / 0912）分别建模，勿跨批次预测（实测跨批 R² 为负） | 已确认 |
