# 数据预处理说明

本文档说明秋月梨 NIR 光谱在自监督预训练之前可选的预处理与离群剔除方法，对应代码：

- `model/preprocess.py`：SNV / MSC / S-G 平滑 / 一阶二阶导数
- `model/outlier.py`：训练前聚类离群剔除

## 1. 概述

原始 NIR 光谱除化学成分信息外，还混有散射、基线漂移、噪声等干扰。
预处理用于在建模前削弱这些干扰、突出有效信号；离群剔除用于去掉
离群样本，避免污染自编码器的特征学习。

处理顺序（在 `run_training` 中）：

```
原始光谱 → 数据预处理（可选） → 离群剔除（可选） → Z-score 标准化 → 训练
```

## 2. 预处理方法

### 2.1 SNV（标准正态变量变换）

逐条光谱减去自身均值、除以自身标准差，消除散射与尺度差异：

$$
x_{snv,i} = \frac{x_i - \bar{x}}{\sigma}
$$

- 消除：加性偏移（基线平移）与乘性缩放
- 处理后每条光谱均值 = 0、标准差 = 1

代码：`preprocess.snv(X)`，逐行（样本）标准化。

### 2.2 MSC（多元散射校正）

逐条光谱对平均光谱做线性回归，校正斜率与截距：

$$
x \approx b_0 + b_1 \cdot \bar{x} \qquad \Rightarrow \qquad x_{msc} = \frac{x - b_0}{b_1}
$$

其中 $\bar{x}$ 为全体光谱的平均光谱（参考光谱）。

- 消除：散射引起的加性/乘性差异
- 与 SNV 目标相同，区别在于参照物是全体平均光谱

代码：`preprocess.msc(X)`。

### 2.3 Savitzky-Golay 平滑（S-G 平滑）

在滑动窗口内用最小二乘拟合多项式，取中心点拟合值作为平滑值，
用于去噪。默认窗口 7、二阶多项式，对应平滑核 $[-2,3,6,7,6,3,-2]/21$。

代码：`preprocess.savgol(X, window=7, poly=2)`。

### 2.4 一阶导数 / 二阶导数

对波长方向求数值导数（`np.gradient`）：

- **一阶导数**：消除基线偏移（常数基线求导后为零）
- **二阶导数**：进一步消除线性基线漂移

代码：`preprocess.derivative(X, order=1)`、`preprocess.derivative(X, order=2)`。

## 3. 预处理应用顺序

勾选多个预处理时，按**固定顺序**叠加（`preprocess.apply_preprocessing`）：

```
S-G 平滑 → SNV → MSC → 一阶导数 → 二阶导数
```

> 注意：SNV 与 MSC 均为散射校正，通常二选一即可；同时勾选会顺序叠加。

## 4. 离群剔除

在训练前做无监督聚类，剔除离群样本：

```
SNV → PCA（10 维） → KMeans（k 个簇） → 簇内距离分位数剔除
```

- 每个样本计算到所属簇中心的欧氏距离
- 距离超过给定分位数的样本判为离群、被剔除
- 样本数 < 20 时不剔除；每簇至少保留约 5 个样本
- 可选「自动选 k」：遍历 2~8 用轮廓系数自动选最优聚类数

代码：`outlier.cluster_outlier_mask(X, k=5, percentile=99.0, pca_dim=10, auto_k=False)`；
自动选 k 见 `outlier.choose_k`。

> 说明：SNV 会消除光谱整体加性偏移与乘性缩放，因此离群剔除主要针对
> **光谱形状异常**的样本（如个别波长出现尖峰），而非整体亮暗不同的样本。

## 6. 代码调用示例

```python
import numpy as np
from model.preprocess import apply_preprocessing
from model.outlier import cluster_outlier_mask

X = np.random.rand(1000, 1024).astype("float32")

# 预处理：启用 SNV 与一阶导数
X = apply_preprocessing(X, {"smooth": False, "snv": True,
                            "msc": False, "deriv1": True, "deriv2": False})

# 离群剔除：返回保留样本的布尔掩码
keep = cluster_outlier_mask(X, k=5, percentile=99.0)
X_clean = X[keep]
```

## 7. 常见问题

**Q：SNV 和 MSC 应该选哪个？**
两者都是散射校正。SNV 逐样本独立、无需参考光谱、速度快；MSC 相对全体平均
光谱校正。通常选一个即可。

**Q：导数应该放在平滑之前还是之后？**
本项目的固定顺序是先平滑再求导，导数会放大噪声，因此平滑在前是合理做法。

**Q：离群剔除会误删正常样本吗？**
按分位数剔除必然删掉固定比例（如 99 分位约 1%）的最远样本，其中可能包含
少量正常样本。若担心误删，可把分位调到 100（不删）或适当下调聚类数。
