# 改动日志

## 2026-09-29

- 【评估】验证对抗域适应（DANN，`model/dann.py`）：梯度反转 + 批次判别器对抗，目标域 0906 无标签训练，跨批预测 0906 R² 基线 -0.482、DANN λ=0.5 -0.934、λ=1.0 -0.537，不升反降。至此光谱层（ComBat/均值方差）、预测层（SBC）、特征层（DANN）三类对齐方法全部无效，结论「跨批预测在现有数据下无法靠算法解决，根源是批间光谱→糖度映射关系的物理差异」，详见《批次校正》3.6


- 【评估】SSL-MTL-CNN 调参（两个方向）：①特征维度 16/32/64 影响不大（CV R²≈0.55）；②重建权重 `recon_weight` 是决定性超参，0.1→0.3→0.5 递升到 0.824±0.119，但低于 MLP 自编码器的 0.873 且折间波动大。结论「暂不采用，框架保留在 `model/cnn_ssl_mtl.py` 备选」，详见《SSL-MTL-CNN》4.2


- 【修复】路径记忆补全（3 处）：①训练完成后自动把新模型目录填入「预测」页签模型目录并记忆；②微调完成后总是把新模型目录填入「预测评估」页签模型目录并记忆（原只在框为空时回填且不持久化）；③新增 `_path_combos` 注册机制，关闭窗口时遍历统一保存全部 16 个路径框当前值，手动输入/粘贴的路径不再丢失


- 【评估】验证「AE 瓶颈特征(16维) + 线性回归」方案：用预训练模型 173754 提取 data-pr 2176 的 16 维特征后做最小二乘回归，全部样本 CV R² 仅 0.52（500 样本 0.54、200 样本 0.43），远低于当前非线性微调头（0.873）和 PLS（0.807）。原因：自编码器特征为「重建光谱」优化而非「预测糖度」，线性回归挤不出糖度信息；这正是需要监督微调（非线性头 + 解冻编码器）的原因。结论「无监督特征 + 线性回归不如当前方案，当前 AE 预训练 + 微调已是无监督与有监督的最优结合」


- 【评估】对比「线性回归（PLS）vs 自编码器微调」：用 numpy 实现 NIPALS PLS，data-pr 2176 五折 CV 下，PLS 最优为 SNV+平滑（CV R²=0.807）、平滑+MSC（0.800）、SNV（0.782）、纯 z-score（0.610）；无标签 PCA 降维 + 线性回归仅 0.23。均低于现有自编码器微调（CV R²=0.873）。结论「自编码器 + 微调仍是当前最优，不建议换线性方案；无标签数据的价值已通过自编码器预训练体现」


- 【修复】实现「固定参考 MSC」：`preprocess.msc` 新增 `ref` 参数、`apply_preprocessing` 新增 `msc_ref` 透传、新增 `compute_msc_ref`；微调时计算并保存参考光谱 `msc_ref.npy`，预测时复用（修复原实现“预测时用预测数据自身平均”的跨批不一致）。验证：批次内性能不变（data-pr 2176 CV R²=0.869，同批预测 ±1度=99%），跨批预测从 -6.79 改善到 -3.92，但仍不可用，结论「MSC 本质上不适合跨批预测，跨批应改用纯 z-score 或 SNV」。详见《批次校正》3.5


- 【评估】发现 MSC 预处理是跨批预测灾难的元凶：`preprocess.msc` 用「各自批次输入数据的平均光谱」做参考，微调/预测跨批不可比，导致旧标签模型预测 0912 的 R² 达 -6.79（完全失控）；去掉 MSC（纯 z-score）后跨批 R² 转正为 +0.175，SNV 为 -1.86。说明此前「跨批预测无解」部分归因于 MSC 而非数据本身。进一步验证：无预处理 + 微调 1596+0906 → 预测 0912 R²≈0.17（弱正向）；吸光度（固化 Dark+REF 公式）与原始 Sample 在 z-score 后 AUC 相近（0.35 vs 0.39）。下一步方向：固定参考 MSC 或改用无 MSC/SNV。详见《批次校正》3.5


- 【评估】找回原始 xlsx 后探查仪器参考字段：`REF` 在所有批次/块中完全相同（均值 19938，固化出厂值而非实测白板），无法做增益归一；各批 `Sample` 原始强度批间差约 4 倍、旧标签内部块间差 3.4 倍；平均光谱形状相关系数 0.99（乘性为主）但样本级分布仍被判别器 100% 区分（SNV/MSC 后 AUC 均 1.0）；预训练数据带 301 维吸光度 `Abs` 与仪器糖度预测 `PredictedValue`，但与 1024 维 `SpectrumData` 无简单换算、标签数据转换时已丢弃。结论「现有 parquet 的 SpectrumData 无法跨批使用，需重新导出标签数据的吸光度/归一化光谱」，详见《批次校正》3.4


- 【评估】补验跨批预测两条对症路线：①SBC 斜率/偏置校正（旧标签 1596 微调 → 预测 0912 后用少量标注样本拟合线性校正），R² 仅从 -5.43 拉到 ≈0.05（拟合斜率 b≈0.12，旧模型预测与真实糖度几乎不相关），无区分度；②仪器归一（Abs/DarkR/REF）——预训练数据有 301 维吸光度 `Abs`（已参考校正），但标签数据只有 1024 维原始强度且原始 xlsx 已删除，无法重建 `Abs`，数据上走不通。结论「跨批预测无法靠后处理校正救回，根源是批间光谱→糖度映射关系不同」，详见《批次校正》3.4
