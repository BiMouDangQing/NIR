# 秋月梨 NIR 近红外光谱分析系统

基于自编码器（Autoencoder）的秋月梨近红外（NIR）光谱无监督分析桌面应用。
通过**自监督预训练**对 1024 维原始光谱建模，提供数据预览、特征学习、降维可视化与异常检测。

- 内置便携 Python 运行时，**无需安装 Python、无需联网**，整个目录拷贝即可离线运行
- PySide6 图形界面，中文「秋月梨」主题
- 支持 CPU / GPU 训练、训练暂停、损失曲线可视化

## 快速开始

双击项目根目录的 `NIR-Pyruspyrifolia.bat` 即可启动。

或在命令行手动启动（使用内置运行时）：

```powershell
cd d:\model\model\NIR-Pyruspyrifolia
.\runtime\python.exe -m QT.app
```

## 数据说明

- 数据为 parquet 格式，共 **24462 条**秋月梨样本
- **SpectrumData（1024 维）**：原始光谱强度，是建模输入
- **Abs（301 维）**：由 NIR 计算的吸光度

## 算法模型

对称全连接自编码器：

```
1024 → 256 → 64 → 16(瓶颈) → 64 → 256 → 1024
```

- 自监督预训练：无标签，用「重建输入」训练，最小化 MSE
- 特征学习：编码器把 1024 维压缩成 16 维瓶颈特征
- 异常检测：重构误差越大越可能是异常样本
- 参数：约 56 万，瓶颈维度可调（2~64，默认 16）

## 训练流程

```
原始光谱 → 数据预处理(可选) → 离群剔除(可选) → Z-score 标准化 → 训练
```

### 数据预处理（可选开关）

| 方法 | 作用 |
| --- | --- |
| S-G 平滑 | Savitzky-Golay 平滑去噪 |
| SNV | 标准正态变量变换，消除散射 |
| MSC | 多元散射校正 |
| 一阶导数 | 消除基线偏移 |
| 二阶导数 | 消除基线漂移 |

### 离群剔除（可选）

训练前先做 `SNV → PCA → KMeans → 簇内距离分位数` 剔除离群样本，
支持手动指定聚类数或**自动选 k**（轮廓系数）。

## 项目结构

